本文件为 2026-11-19 保存的正式工程副本，与分享包快照一致。

## 轨道与素材依赖

| 轨道（trackIndex） | 类型 | 外部音频依赖 |
| --- | --- | --- |
| 0 main vocal / 1 空间层-主歌 / 2 空间层-主歌（空轨）/ 6 main vocal 2 / 7 空间层-副歌 / 8 harmony / 9 harmony2 | ACE 合成轨（Sing，共 7 条） | 无（打开即可合成试听） |
| 3 雨爱-drums / 4 雨爱-bass / 5 雨爱-others | 音频轨（Audio，共 3 条） | `Samples/雨爱-drums.ogg`、`雨爱-bass.ogg`、`雨爱-others.ogg` |

- 伴奏 3 轨为**官方分轨**，版权第三方，未随包分发 → 打开工程时这 3 轨显示缺件/离线，
  属预期行为；人声调教、参数曲线、唱名编辑均不受影响。
- 如你已合法持有伴奏，可在 ACE Studio 中右键缺件轨重新链接到本地文件；
  或静音/删除伴奏轨后单独听人声（删除前请自行备份）。
- 工程内时间几何：ticks = 640/秒；主歌首句约在项目时间 18.7s，与
  `../lyrics/rainlove_ja_zh.srt` 的时间轴对齐（SRT 时间 ≈ 工程时间 ≈ 成片时间）。

## 两个歌词层（重要）

1. **唱名音符层**：全假名，逐 mora 对应音符，是调教与发音的实际载体。
   日语 g2p 仅接受假名；空白唱名与 `-` 表示延音（melisma），不要填汉字。
2. **编曲区第 3 行「歌词」栏**：独立文本层，汉字假名混写，仅供阅读，不影响发音。
   该栏文本已于 2026-11-19 按 SRT 校订完毕；如仍需校订，只改该栏文本，
   勿动唱名/音高/音素 pin。
