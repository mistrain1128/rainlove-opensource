# 雨爱 MV 场景生图方案

## 目的与原则

为 45 个剧本镜头建立可复用的场景参照；单张图片为单一全画面，采用 16:9 横向构图。人物、伞、雨滴身影和歌词是后续独立控制的元素，场景图主要提供空间、光线和气氛。并非每个剪辑镜头都需要一张独立背景。

现实线为雨夜至清晨的日本动漫都市；家中画面为白天回忆。统一蓝灰雨夜与暖黄灯光、细腻动画背景与真实空间比例，黎明变为灰蓝和少量淡金。城市可由剪辑连接，不强制每个地点建立严格的连续几何关系；同一段连续动作内维持机位、地标和方向一致。雨天始终存在。

## 连续场景与跳切

- 站牌段落：先锁定一个站棚与站牌造型；听到滴水变化、抬头、走出屋檐都由对应主视角及其近景组成。雨声变化发生在角色反应前。
- 天桥段落：先锁定桥面几何、栏杆、路灯、楼梯以及人物行进方向；进入桥的镜头可切换，但桥面相遇、消散、转身须在同一空间轴线上。
- 便利店到站牌、街道到家中回忆、天桥到晨景：允许跳切，用车身/伞面遮挡、雨滴匹配和声音先行解释地点与时间。
- 结尾 4:12–4:14 为车内转头近景；4:14 后切车外固定远景。歌词文字在后期校对和叠加。
- 非叙事主体的水洼、城市远景、檐边雨可复用；有明确人物动作或明显唯一车辆运动的画面避免机械重复。

## 剧本补充（不覆盖原剧本）

街区平面为可调整参考，不能要求全部景物可由一个机位看见。1:40 可以用站牌檐滴水声先行并切回站牌，表示时间和地点跳转；无需拍完整折返。2:04–2:40 用行人、车和伞遮挡切入不同街景，然后以天桥楼梯建立镜头确认追赶已到桥下。其余故事、4:12 车内近景、雨声淡出后保留等约定沿用原剧本。原剧本时间约 4:19.6，最终音乐版本需重新对轴。

## 检查与状态

场景图是视觉参照而不是完成视频；最终需要检验角色比例、镜头视线轴、建筑结构与实际生成片段的头尾帧。禁止将计划标为已校准的连续视频。此方案允许生成结果出现候选版本并供创作者挑选；原图按用户偏好不作污点清除。
