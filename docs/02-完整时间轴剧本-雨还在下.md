# 《雨还在下》MV 时间轴剧本

## 基本设定

- 主角：洛天依。角色造型、服装与具体画风以之后确认的参考图为准；全片尽量保持同一套主要造型。
- 世界：受日本动漫都市启发的虚构城市。现实线从雨夜延续到清晨；暖灰色的雨天白昼属于家中回忆。
- 结构：车站 → 便利店街道 → 公交站牌 → 山坡观景台与雨夜城市 → 市区人行天桥 → 天桥另一侧的公交站。家中仅出现在回忆里。观景台与市区之间用切镜和时间省略连接，不要求她在相邻镜头里走完全程。
- 音乐基准：以最终确认的洛天依演唱混音为准。以下时间暂按参考版本约 4:19.6 编排，歌词和切点需对最终混音重新校准，不作为逐字对轴。
- 时间标注：区间前闭后开；相邻镜头自然衔接。镜头长度为剪辑目标，并非要求每段一次生成完成。
- 已制作的前段家中回忆可保留乐正绫。镜头 18 之后，乐正绫的雨中身影只在天桥段出现一次：从镜头 29 淡入，持续至镜头 31 淡出，不在其他地点再次显现。面庞保持朦胧，以柔和淡入、淡出呈现，不做身体化成雨滴或碎片的效果。
- 画面色彩：夜晚深蓝、灰紫、路灯暖黄；回忆为雨天柔和暖灰；将明时逐渐转灰蓝；清晨加入克制的淡金和浅蓝。雨始终存在。
- 核心动作：天桥上缓缓放低伞，让雨落在肩头；离开时重新撑好。后续镜头以自然撑伞和人物位置表现情绪，不要求伞面偏向空位。

## 声音与文字原则

歌曲是一条连续的主音轨。雨声作为独立叙事音轨叠加，在主唱密集时适当降低，保留近处伞面、屋檐、地面与远处城市的不同层次。雨声变薄只针对近处雨纹理，不必让歌曲或远方城市声一起消失。

字幕与店招后期添加；“Rainie love”为虚构店招文字，使用时以实际唱句为准。日语字幕以确认的歌词为准，不由画面生成模型负责精确拼字。口型只安排在可控制的少量演唱近景，其余通过侧脸、背影及环境镜头承接。

## 可复用素材与连续性

- **水洼与路灯倒影**：镜头 01 可择取不同片段或裁切方式用于间奏与尾声；同一素材如用于清晨，应考虑光色及时间差异。
- **站牌檐边滴水**：前段建立规律，镜头 20 再现同一视觉环境；声音另行编辑出变稀疏的变化，不依赖画面本身自动产生。
- **夜雨楼窗远景**：可用于片头或间奏过场。镜头 39 的黎明景色建议另制或专门调整，避免明显的夜景重复。
- **山坡观景台与城市远景**：镜头 23–26 可共用同一组城市灯光和天气；从站牌到山坡、从山坡回市区均通过切镜省略路程。观景台需另制场景参考，不把现有天桥图当作山坡地点。
- **天桥相同构图**：镜头 28 与 35 采用相同视角进行叙事对照；它们的角色数量与天光不同，不要求直接复用同一视频。
- **车窗雨痕**：可在副歌与结尾呼应；洛天依的手、头和视线涉及连续动作，建议单独制作。
- 避免重复使用带有明显唯一动作的行人和车辆；雨滴升降方向、洛天依衣着、透明伞与光色需跨镜头一致。
