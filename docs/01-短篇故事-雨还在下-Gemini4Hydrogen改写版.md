# 雨还在下

车站的玻璃门向两侧滑开时，夜里的凉风裹着细雨扑面而来。

洛天依在屋檐下站了一会儿，等匆忙穿过站口的人群散开，才撑开那把透明的伞。她像往常一样，下意识地把伞柄往身旁倾了倾。雨点顺着伞面的另一侧汇成细流，而她自己的左肩却露在雨丝里，深灰色的风衣布料很快洇出一片深色。

她低头看了一眼湿透的肩头，没有把伞挪回来。

城市在雨夜里依然亮着灯。便利店的橱窗上挂满细密的水珠，室内暖黄的光透出来，照亮了湿漉漉的砖面。她路过窗前时，刚好看见里面有人把一杯热饮递到同伴手里。那只伸出去的手，让她的脚步停了一瞬。

记忆里的另一个雨天，也是这样潮湿而安静。家里的窗玻璃蒙着一层白雾，低桌上摆着两只杯子。她靠着窗坐在地毯上，看屋檐外连成线的雨。有人坐在她身旁，把温热的杯子轻轻推到她手边。那天到底说了什么，她已经记不清了，只记得指尖传来的温度，还有窗外很近、很密的雨声。

车轮碾过积水的声音把她拉回夜色。她继续往前走，在公交站牌的雨棚下坐了一会儿。公交车进站、开门，又驶离。她身旁的座位一直空着，雨棚檐边的水滴一颗接一颗，规律地砸在地面上。

她伸出手，想去接一滴从伞沿滑落的雨水。

可那滴水没有落进掌心，而是在半空中轻轻一顿，缓缓向上浮起。那一瞬，敲打在伞面上的雨声仿佛退远了一层，只剩下城市深处连绵的雨幕。洛天依抬起头，看见路边的小水洼里，正并肩映着两道走过的影子。她猛地转身，身后空荡荡的人行道上，只有她自己。

又一颗雨滴浮到眼前。澄澈的水珠里短暂地映出窗边的低桌、两只杯子，以及那只朝她伸来的手。她小心翼翼地伸出指尖触碰，水珠却在触及的瞬间散开，顺着指缝滑落。一辆公交车恰好驶过，带走了橱窗里漏出的暖光，玻璃上只剩下一道道长长的雨痕。

她走回站牌的屋檐下。不知什么时候，檐边原本规律的滴答声变得稀疏，伞面附近的雨声也轻了下来。她抬眼望向街道深处——一盏昏黄的路灯下，雨雾仿佛聚成了一道朦胧的身影，安静地站在那里。

她迈步走出屋檐。路口的信号灯变换，撑伞的行人从她身侧擦肩而过；等她穿过马路，那道身影已经退到了更远的地方。她加快脚步，追过亮着灯的店面与空旷的支路，沿着湿滑的台阶一路走上人行天桥。

天桥下，车灯在雨中拉出细长的光带；城市向四面八方铺开，楼宇间的万家灯火像散落在深蓝夜色里的星。那道身影站在桥的另一端，终于没有再退后。

洛天依放慢脚步走近，试着慢慢伸出手。

风从高楼的缝隙间吹过。桥上雾气微动，那道模糊的轮廓在雨幕里渐渐变淡，连同那段隔着雨窗的温暖回忆一起，轻轻融进了夜色里。

这一次，她没有再追。

当完整的雨声重新回到天桥上时，她缓缓放低了手中的伞。伞依然撑着，只是不再遮在头顶。冰凉的雨点顺着发梢落在肩头，她闭上眼睛站了一会儿；再睁开眼时，天边深蓝的夜色已经悄悄退成了一抹灰蓝。

洛天依握稳伞柄，转身走下天桥。经过桥下亮着余晖的路灯时，她把伞重新举回头顶，几滴水珠从伞沿轻晃着滑落。黎明前的街道依然潮湿，路旁的水洼里映出逐渐变浅的天空，鞋尖轻轻踏过边缘，水纹便把倒影温柔地揉散。远处高架铁路上驶过清晨的第一班电车，楼与楼之间的云层微微透亮，一弯很淡的彩虹正悄然浮现。

清晨的公交车缓缓停靠在站台。她收拢透明伞，等前面的乘客上车后才迈步上去，在靠窗的双人座坐下。湿漉漉的伞立在膝边滴着水，身旁的座位空着，她没有再回头确认。她只是望着玻璃上向下滑落的雨痕，把手掌轻轻贴上微凉的窗面。片刻后，她收回手，转过头，安静地看向车辆前进的方向。

公交车驶离站台，汇入渐渐明亮起来的街道。镜头留在空荡的站台屋檐下，檐边的水滴依然一颗接一颗，落进地面的水洼。

雨还在下。
